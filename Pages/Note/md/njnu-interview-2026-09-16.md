### 2. Wavelet Analysis（小波分析）

**必须能脱口而出的骨架**：

小波分析是一种 **时–频同时局部化** 的信号分析方法。傅里叶变换只能告诉我们信号里有哪些频率，却丢掉了「什么时候出现」；短时傅里叶加了窗，但窗宽固定，高频低频同一套窗，不够灵活。

小波用一个 **母小波**（mother wavelet）\(\psi(t)\)，通过平移（对应时间位置）和伸缩（对应频率尺度）得到一族基函数：

\[
\psi_{a,b}(t) = \frac{1}{\sqrt{a}}\,\psi\!\left(\frac{t-b}{a}\right)
\]

- \(a\)：尺度（scale），大尺度看轮廓/低频，小尺度看细节/高频  
- \(b\)：平移（translation），定位在时间（或空间）上的位置  

**连续小波变换（CWT）**：信号与小波做内积，得到时–频（或时–尺度）系数图。  
**离散小波变换（DWT）**：对 \(a, b\) 按二进制采样，可高效实现；常用基如 Haar、Daubechies、Mexican hat。  
**多分辨率分析（MRA）**：把信号拆成 **近似（低频）+ 细节（高频）**，可逐层分解。

**在地学 / GIS 里能用在哪**（面试加分点）：

- 气候序列（气温、降水、NDVI）的多时间尺度突变与周期检测  
- DEM / 影像的多尺度地形细节分离、压缩  
- 遥感影像融合与去噪  
- 与傅里叶对比：非平稳序列更适合小波

**一句话收束**：

> 小波 = 可伸缩的窗。低频用宽窗看大势，高频用窄窗看细节，时频一起定位。

**雷区**：不要说「四级随便考的 / 运气好 / 题简单」——显得轻浮或不诚实。

### 4. 简单介绍 PCA（主成分分析）

**定义**：一种 **无监督线性降维** 方法。把 \(p\) 个可能相关的变量，变换成少数几个 **互不相关** 的综合指标（主成分），尽量保留原数据的方差信息。

**步骤（背熟）**：

1. 数据标准化（均值 0、标准差 1），消除量纲影响  
2. 计算相关系数矩阵 / 协方差矩阵  
3. 求特征值与特征向量  
4. 按特征值从大到小排序，取前 \(k\) 个特征向量作为新基  
5. 原始数据投影到新基上，得到主成分得分  
6. 用 **累计方差贡献率**（常取 ≥ 85%）决定保留几个主成分  

**几何直观**：找数据云团「最散开」的方向（最大方差方向）作为第一主成分，第二主成分与之正交、方差次大，依此类推。

**注意说清楚的边界**：

- 只抓 **线性** 结构，对非线性流形无效（可用 Kernel PCA / t-SNE / UMAP）  
- 主成分是原变量的线性组合，**可解释性弱于原始变量**  
- 对异常值敏感，需先做标准化与异常处理  

**地学例子**：高光谱波段高度相关，PCA 前几个主成分往往能保留 95% 以上信息，方便分类与制图。

### 5. 和 PCA 原理非常相似的方法是什么？

面试官这里几乎肯定是想听你 **建立知识网络**，而不是孤立背一个算法。最常被并列追问的有三个，按「像的程度」准备：

#### （1）因子分析（Factor Analysis）——最常标准答案

| | PCA | 因子分析 |
|---|---|---|
| 目标 | 降维、概括方差 | 解释 **潜在公共因子** |
| 模型观 | 变量 = 主成分的线性组合（精确变换） | 变量 = 公共因子 + 特异因子（生成模型） |
| 关注 | 尽量保留总方差 | 尽量解释变量间 **相关性** |
| 旋转 | 一般不做 | 常做方差最大化旋转，提高可解释性 |

一句话：**PCA 是变换，因子分析是建模**；两者都从相关矩阵/协方差结构出发，都做线性组合降维，所以「原理非常相似」。

#### （2）独立成分分析（ICA）

- PCA 要求主成分 **不相关**（二阶统计量）  
- ICA 要求源信号 **统计独立**（高阶统计量）  
- 经典应用：盲源分离（鸡尾酒会问题）  
- 关系：常先 PCA 白化，再 ICA 分离

#### （3）奇异值分解（SVD）

- PCA 在数学上可通过 **对中心化数据矩阵做 SVD** 来实现  
- \(X = U\Sigma V^\top\)，右奇异向量即主成分方向  
- 也是潜在语义分析（LSA）、推荐系统的基础  

**现场可用的答法**：

> 「和 PCA 最像的是因子分析：都从相关/协方差结构出发、都做线性组合降维。区别在于 PCA 侧重保留方差、是可逆变换；因子分析侧重解释潜在公共因子、是生成模型。再往外还有 ICA（独立而非仅不相关）和 SVD（PCA 的矩阵分解实现）。」

### 7. 除南师大外还报了哪些学校？择校怎么考虑？

**建议框架**（诚实 + 有主心骨，避免显得海投或随便）：

1. **报了谁**：如实列出 2–4 所，层次可拉开（冲 / 稳 / 保）。  
2. **为什么报**：每所学校用一句「方向匹配点」，不要只说「学校好」。  
3. **为什么把南师大放在重要位置**：具体到实验室方向、导师工作、城市或培养特色。  
4. **若被问「更想去哪」**：统一口径——以 **研究方向匹配度** 为第一标准，南师大是优先选项之一；避免贬低其他学校。
