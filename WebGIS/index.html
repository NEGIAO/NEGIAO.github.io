NEGIAO WebGIS

Application Purpose

NEGIAO WebGIS is a web-based geographic information system designed for interactive spatial data visualization, cloud map layer management, and geospatial analytics.

Google OAuth & Data Transparency

We use Google Sign-In (OAuth 2.0) solely to authenticate user identity and securely store personal geospatial map projects and customized platform preferences in the cloud. We do not access, share, or store any sensitive personal user data.
