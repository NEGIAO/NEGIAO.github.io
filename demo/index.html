NEGIAO's WebGIS

A Web-based Geographic Information System (GIS) platform for spatial data visualization, interactive mapping, and cloud project storage.

Application Purpose and Functionality

NEGIAO's WebGIS is designed to provide users and GIS analysts with accessible, cloud-based geographic information tools:

Spatial Data Visualization

Allows users to display and render vector map layers (GeoJSON, Shapefile) and raster basemaps interactively in the browser.

Spatial Analysis Tools

Provides core geographic information analysis utilities including distance measurement, spatial attribute queries, and buffer generation.

Cloud Map Synchronization

Enables registered users to store, manage, and sync their custom WebGIS map projects and layer configurations across devices.

Google User Data Usage and Transparency

NEGIAO's WebGIS uses Google OAuth 2.0 to allow users to sign in. In full compliance with Google API Services User Data Policy:

  • Requested OAuth Scopes: Basic profile scopes including OpenID, Email address (`email`), and Basic Profile (`profile`).
  • Purpose of Data Collection: We request user profile information strictly to authenticate users and associate their saved WebGIS projects and custom map layer configurations to their personal account.
  • Data Protection & Privacy: We strictly do NOT sell, share, or transfer user Google data to third parties. All data transmission is encrypted over HTTPS.
