Application Name: NEGIAO's WebGIS

A Web-based Geographic Information System (GIS) for spatial data visualization and analysis.
(基于 Web 的地理空间数据可视化、地图制图与空间分析交互平台)

Application Purpose & Functionality (应用功能与用途说明)

NEGIAO's WebGIS provides cloud-based GIS mapping tools for developers and geographic data analysts:

Spatial Data Visualization

Supports vector layers (GeoJSON, Shapefile) and raster basemap rendering and overlays.

Interactive Spatial Analysis

Provides buffer analysis, coordinate measurement, and spatial attribute querying tools.

User Cloud Storage

Allows users to save and sync their map styling and GIS project configurations in the cloud across devices.

Google User Data Usage & Transparency (Google 用户数据说明)

NEGIAO's WebGIS uses Google OAuth 2.0 for authenticating users. In compliance with Google API Services User Data Policy:

  • Scopes Requested: Basic authentication profile scopes including OpenID, Email address (`email`), and Basic Profile (`profile`).
  • Purpose of Data Use: We request user email and profile information solely to create and manage user accounts on NEGIAO's WebGIS, and to bind and sync saved user GIS map projects to their profile.
  • Data Protection: We do not sell, share, or transfer user Google data to third parties. All communications are strictly encrypted via HTTPS.
